# Sales-Data-Analysis-Using-Python
This project demonstrates sales data analysis using Python, Pandas, NumPy, and Matplotlib. It includes data cleaning, exploratory data analysis (EDA), visualization of sales trends, and business insights to support data-driven decision-making.

## Business Problem

Businesses generate large amounts of sales data every day. This project demonstrates how Python can be used to analyze sales performance, identify trends, and support business decision-making.

## Objectives

- Analyze sales performance by category
- Evaluate sales across regions
- Assess profitability
- Identify monthly sales trends
- Create visualizations for decision-making

## Dataset

The dataset contains the following variables:

- Date
- Category
- Sales
- Profit
- Region

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Visualizations

### Sales by Category
Shows total sales generated by each product category.

### Sales by Region
Compares sales performance across different regions.

### Profit by Category
Shows profitability of each product category.

### Monthly Sales Trend
Displays how sales changed over time.

## Key Findings

- Electronics generated the highest sales.
- Sales performance varied across regions.
- Profitability differed between categories.
- Monthly sales showed changing trends over the reporting period.
